GIFT FOR HER — KOMBINASI

Ekstrak ZIP. Buka folder di VS Code, lalu index.html lewat Live Server.
Bisa juga membuka index.html langsung di browser.

Urutan tetap: pembuka → surat → pohon hati → I Love You + waktu bersama
→ kartu kenangan dan pesan terakhir.
Teks dan kartu dari file yang kamu kirim tetap dipakai.
Pohon bunga diganti pohon dengan 1.600 hati kecil dan animasi tumbuh.
Countdown diganti penghitung waktu sejak tanggal awal kalian.

EDIT ISI: buka DATA di bagian paling atas script.js.
TANGGAL: togetherSince: "" harus diisi tanggal awal yang benar.
Contoh format (bukan tanggal kalian):
togetherSince: "2024-02-23T00:00:00+07:00"
Penghitung menampilkan total HARI, lalu sisa JAM (0–23), MENIT, DETIK.
Jika tanggal kosong/tidak valid, tampil petunjuk dan tanda —.
Tanggal di masa depan akan menampilkan nol sampai tanggal itu tiba.

FOTO: masukkan foto ke assets/ dan ubah image pada DATA.cards.
MUSIK: masukkan assets/music.mp3. Aktifkan dengan tombol ♫.
Foto dan lagu tidak disertakan karena tidak ada pada lampiran.
Gunakan assets dari project lama agar foto/lagu sebelumnya tetap tersedia.

Tidak perlu npm. Font Google memerlukan internet; bila offline memakai
font cadangan. Setelah mengedit, simpan file dan tekan Ctrl+F5.
